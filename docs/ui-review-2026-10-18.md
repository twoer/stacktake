## P0 — 功能性缺陷

### 1. toast 全程静默：`<Toaster>` 未挂载

- **证据**：`ff4b9e5`（更名 Stacktake 那次）在 `App.vue:157` 挂过 `<Toaster position="top-center" :duration="4000" />`；`4a924d7`（G1）重写 App.vue 后消失，此后每个提交都没再挂上。当前 `src/` 全树 grep `Toaster` 只命中 `components/ui/sonner/`（组件定义自身，无任何引用方）；`dist/assets/*.js` 也没有（未打包，佐证运行态同样没有）。`Assets.vue:852` 的注释「vue-sonner 自己不读 .dark class，theme 必须显式传」指向的正是这个不存在的挂载点——说明当时是有意要传 theme 的，挂载点是丢失不是砍需求。
- **影响**（全部 `toast.*` 调用静默 no-op）：
  - `Assets.vue:217-222` 清理结果：**腾出多少 / 失败原因不可见**（行会随重扫消失，但「为什么被拒」只剩服务端日志）；
  - `Assets.vue:130` 复制路径无确认；`Assets.vue:122`「访达中显示」失败无提示；
  - `Assets.vue:743` 重扫完成/失败无提示；`Settings.vue:70-108` 保存 / 恢复默认 / 清空缓存 / 立即重扫四个动作全部无反馈。
  - 违反 ui-ux-pro-max「Feedback / Loading States」高优先级规则（async 操作必须有可见反馈）。
- **修法**：App.vue 根部恢复挂载，并顺手把 theme 传上（`useTheme` 是同文件可用的模块级单例）：
  `<Toaster :theme="theme === 'dark' ? 'dark' : 'light'" position="top-center" :duration="4000" />`。
  一行级改动，但用户可见度最高。

## P1 — 可访问性（对比度 / 焦点，均为实测值）

### 2. 浅色下「可回收」绿色数字不达 4.5:1

- `text-green-600`（#16a34a）白底实测 **3.30:1**，用在 text-xs 的可回收数字上（`Assets.vue` 968 / 1016 / 1024 / 1061 / 1084 / 1156 / 1164 / 1270 共 8 处：分节小计、体积列染绿、检查器、状态栏）。深色 green-500 实测 8.69:1，无问题——**只有浅色不达标**。
- 修法：浅色改 `green-700`（实测 5.02:1），即 `text-green-700 dark:text-green-500`。更好的做法是提成语义 token（`--color-reclaimable`，深浅两套值）——现在 green-600/700 是裸色板值，是全项目唯一不用 token 的语义色。

### 3. 浅色焦点环对比度不足

- `--ring: oklch(0.708)` = #a1a1a1，白底实测 **2.59:1**，且 `ring-1` 只有 1px——低于 WCAG 2.2 焦点可见性 3:1（非文本）。深色 `--ring`（#737373 on #0a0a0a）实测 4.18:1，达标。全局焦点环走 `style.css:94-97` 的 base 兜底 + 各处的 `focus-visible:ring-1 ring-ring`，grep 确认 `ring-ring` 只用于焦点环，改令牌不影响别处。
- 修法：浅色 `--ring` 加深到 `oklch(0.55 0 0)`（≈#737373，实测 4.7:1）。注意这与「线条弱化」不冲突——弱化的是 `--border`（分隔线），焦点环是交互指示，方向是更清楚。

### 4. chip / kbd 的小字 4.34:1 贴边（擦边，不严重）

- `muted-foreground`（#737373）在 `muted` 底（#f5f5f5，标签 chip、`/` kbd）上实测 **4.34:1**，略低于 4.5。chip 是 10px 文字。**如实说明：这是「擦边」不是「明显读不了」**，且 chip 内容是可筛标签、非关键信息。
- 修法（任选）：chip 文字改 `text-foreground/70`；或 kbd 的 `text-muted-foreground/70` 去掉 /70。

## P2 — 交互与一致性

### 5. 两个确认弹窗没有焦点管理

- `Assets.vue:1311-1383`（整仓/缓存/AI 清理）与 `1388-1431`（清理产物）：`role="dialog" aria-modal="true"` 已有、Esc/遮罩/取消都能关，但**打开时焦点不进 dialog、关闭不还原焦点、无焦点圈禁**——Tab 会穿到背后的表格上。破坏性确认是键盘用户的关键路径，这里断档。
- 修法：打开时 focus「取消」按钮（安全默认）、关闭后还原焦点；加焦点圈禁（遮罩层 `@keydown.tab` 拦或在 dialog 内循环）。规模小、收益直接。

### 6. 设置页三小项

- a. **输入框只有 placeholder 没有可见 label**（`Settings.vue:153-174`，placeholder「绝对路径，或 ~ 开头」）——违反表单规则「placeholder-only label」，placeholder 在输入后消失，用户忘了这行是干什么的。修法：行首加「路径」小标签或 `sr-only` label。
- b. **「不存在」提示与正文同色同字重**（`Settings.vue:161-166`）——存在性警告应该更醒目（`text-foreground` 或配图标），现在几乎看不见。
- c. **「保存」按钮图标是 FolderOpen**（`Settings.vue:187`）——文件夹图≠保存，换 Save / Check 一类。

### 7. 设置页顶栏缺拖动区（平台适配）

- `titleBarStyle: "Overlay"` 下只有带 `data-tauri-drag-region` 的区域能拖窗口（现只有 `App.vue:109` 侧栏 28px 空带和 `Assets.vue:753` 工具栏）。**Settings.vue:126 顶栏没有**——设置页主区顶部完全拖不动。另外 Windows 窗口按钮在右上，Assets.vue 用 `pr-[140px]` 避让（`Assets.vue:850`），设置页顶栏没有对应处理；目前右侧无控件暂不碰撞，但以后加按钮就会撞上。

### 8. 搜索框宽度动画动的是 layout 属性

- `Assets.vue:829` `transition-[width]`：聚焦时 w-32→w-52，会把右侧三个工具栏控件推着走。动画规则明确 avoid animating width/height（layout thrashing + 邻居抖动）。修法：定宽 `w-52`，聚焦反馈交给 ring/底色变化。

### 9. 表格排序缺 `aria-sort`

- 列头按钮有 `aria-label`（`Assets.vue:932-949`）但没声明 `aria-sort`，屏幕阅读器读不出「当前按哪列、什么方向」。一行修复：`:aria-sort="sortKey === c.key ? (sortDesc ? 'descending' : 'ascending') : 'none'"`。

### 10. 进度条缺 progressbar 语义

- 扫描进度条是纯 div（`Assets.vue:888-893`、`Settings.vue:130-135`），补 `role="progressbar" aria-valuenow/min/max` 成本一行。

## P3 — 可选增强（不构成问题，列全供参考）

- **侧栏分组无键盘导航**：6+1 个分组只能 Tab 逐个走；表格行已有 ↑↓ 选择，侧栏可补 ↑↓ 或 Cmd+1…9。
- **右键菜单键盘不可达**：`role="menu"`/`menuitem` 有了，但键盘没有入口（ContextMenu 键）。检查器动作条是等价路径，可接受；要补就加 keydown。
- **Windows 滚动条风格**：主列表用默认滚动条，Windows 上是经典灰条，与整体淡线条不一致；macOS overlay 无感。可统一细滚动条。
- **10px 字号纪律**：10px 只用于真装饰（kbd 提示、chip）。信息性文字保持 ≥11px 的现状即可，这是密度路线的有意取舍，不建议回调——但要小心别把 10px 扩大到新内容。

## 做得好的（审查不是只挑刺）

- **反馈链路完整**：首扫 spinner + 进度文案 + 「约 26 秒」预期管理（`Assets.vue:911-919`）、真实进度条（U2）、错误条、空状态带动作出口、状态栏常驻「数据更新于」+ 超一天加重视觉。
- **破坏性操作三道闸**：确认弹窗把「删什么 / 删多少 / 去哪（废纸篓可恢复）/ 服务端怎么复核」逐条写明；AI 会话「删除后不会自动重建」单独声明（`Assets.vue:1330-1332`）；产物清理与整仓清理分开两个弹窗，不共用文案。
- **键盘**：`/` 聚焦搜索、↑↓ 选行、Esc 分层关闭（弹窗 > 菜单 > 选中态）、focus-visible 与 cursor-pointer 在 base 层全局兜底（`style.css:88-97`）——这两条兜底是「一定会有后来者漏挂」的正确解法。
- **reduced-motion**：spinner 降速不停转、fade 门控、进度条 `motion-reduce:transition-none`。
- **数据呈现纪律**：数字右对齐 + tabular-nums、名称列吃剩余宽度、分节 hairline 是表内唯一结构线、多数派标签抑制（数据驱动）、占比条按 max 归一化不用 sum——都是想清楚了的决策，不是抄的。
- **深浅双主题全 token 驱动**，侧栏选中态明序在深色下的处理（挂 `bg-accent` 而非 `bg-background`，`App.vue:117-119`）想过了；`index.html` 首帧前定色避免深色系统下闪白。
- **图标**：双库分工有文档、stroke 宽度对齐算过、无 emoji；`aria-current="page"`、图标按钮 aria-label/title 齐全。
